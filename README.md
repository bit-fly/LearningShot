# LearningShot（在线培训学习助手，Edge / Chrome 插件）

浏览器插件：在进行网页在线培训时，一键抓取整页或框选局部内容，让AI助手辅助理解学习内容，自定义集成带vision的API 用于截图的内容识别。

## 功能

- **抓取整页**：用 Readability 算法提取正文（去除导航/广告等噪音），交给大模型归纳为结构化要点（核心概念 / 详细要点 / 示例）。
- **框选解读**：两种模式可切换
  - 文本选中：读取当前页面的文字选区
  - 区域截图：拖拽框选一个区域，截图后用多模态模型解读（适合图表、图片类内容）
- **普通解读 / 题目解答**：普通解读始终可用；题目解答（Quiz answers）由设置页中的"在主界面显示答题助手"开关控制，默认关闭。开启后会给出参考答案 + 简要说明，并在结果开头提示"仅供自测练习参考，AI解读"。
- **统一选取模式**：普通解读和题目解答共享同一组选取模式，可分别使用文本选中或区域截图，不会因切换阅读模式而重置。
- **历史记录**：每次解读结果本地保存（`chrome.storage.local`），侧边栏内可点击回顾。支持单条"导出"为 `.md` 文件，或"导出全部"一次性导出成一个 Markdown 文件。
- **流式输出**：解读结果打字机效果实时显示。
- **界面语言切换**：侧边栏/设置页右上角"中/EN"按钮，切换插件自身界面语言（不影响 AI 输出语言，AI 输出语言在设置页单独配置）。
- **深浅色主题切换**：侧边栏/设置页右上角🌙/☀️按钮，一键切换深色/浅色界面。
- **一键测试连接**：设置页填写网关地址/API Key/模型名后，点击"一键测试"立即发起一次最小请求验证配置是否正确，无需先保存。
- **追问文档附件**：在“继续讨论”中可添加 TXT / MD / CSV / JSON / HTML / XML / PDF / DOCX，扩展会在本地提取文字后随问题发送；原文件和附件文字不写入历史记录。

## 安装与操作步骤

### 一、准备环境和安装包

1. 使用桌面版 Chrome 114+ 或 Edge 116+。手机浏览器不支持本插件的侧边栏功能。
2. 获取 `LearningShot-v0.1.0.zip` 后，将它解压到本地固定目录。不要直接在压缩包内运行。
3. 打开解压目录，确认 `manifest.json`、`background.js`、`sidepanel.html` 等文件直接位于该目录中，而不是再嵌套一层子目录。
4. 压缩包不包含任何 API Key。每位成员都应使用自己的网关配置，不要把个人 API Key 写入压缩包或转发给其他人。

### 二、在 Chrome/Edge 中加载插件

1. Chrome 地址栏打开 `chrome://extensions/`，Edge 地址栏打开 `edge://extensions/`。
2. 打开页面右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”（Load unpacked）。
4. 选择刚才解压后的目录，必须选择**包含 `manifest.json` 的那一层目录**。
5. 加载成功后，扩展列表中应出现 **LearningShot**。如提示找不到 `manifest.json`，通常是选择了错误的目录层级。
6. 可在扩展卡片中点击图钉，将 LearningShot 固定到浏览器工具栏，之后更容易打开侧边栏。

> 如果使用的是源代码项目而不是本压缩包，请先在项目根目录运行 `npm install` 和 `npm run build`，再选择项目下的 `dist` 目录加载。团队日常使用应直接加载本压缩包解压后的目录。

### 三、首次打开和配置

1. 打开一个需要学习的普通网页，并保持该页面为当前活动标签页。
2. 点击工具栏中的 LearningShot 图标，打开右侧的侧边栏。
3. 点击侧边栏右上角的齿轮图标进入“设置”。
4. 按下面的说明填写配置：
   - **网关地址**：填写 OpenAI 兼容网关的 Base URL，例如 `https://llm-gateway.internal.company.com/v1`。只填写 Base URL，不要再追加 `/chat/completions`，插件会自动拼接接口路径。
   - **API 密钥**：填写个人 API Key。该值只保存于当前浏览器的本地存储，不会写入项目文件。
   - **模型名称**：填写网关实际支持的模型名，例如 `gpt-4o` 或 `qwen-vl-max`。如果要使用区域截图，模型必须具备 Vision（视觉/图像识别）能力。
   - **输出语言**：填写希望 AI 使用的语言，例如 `中文` 或 `English`。
   - **在主界面显示答题助手**：需要自测题目参考答案时开启；默认关闭。该功能仅用于自测和练习参考，不应代替正式考试或计分答题。
5. 点击“保存”，看到“已保存”提示后，再点击“测试连接”。
6. 首次测试连接或首次抓取网页时，浏览器可能弹出访问权限提示。确认网关地址和使用场景无误后点击“允许”。拒绝权限会导致网页抓取、区域截图或网关测试无法正常完成。
7. 如果测试失败，请检查是否已连接公司网络/VPN、网关地址是否可访问、API Key 是否有效，以及模型名称是否拼写正确。

### 四、抓取整页文字并解读

1. 在目标网页中滚动或打开到要学习的页面，并确保该页面是当前活动标签页。
2. 在侧边栏的“阅读模式”中选择：
   - **解释**：生成结构化知识梳理、核心概念、详细要点和示例。
   - **自测**：仅在设置中开启答题助手后显示，用于生成题目参考答案和简要说明。
3. 在“捕获范围”中选择“捕获整页”。
4. 点击“捕获文字”。插件会提取当前网页的正文并流式生成结果，请等待侧边栏显示完成。
5. 生成结果后，可以在“继续讨论”区域输入追问；结果也会保存到本地历史记录中。
6. 点击追问框旁的📎按钮可以添加文档附件；默认最多 5 个文件、单文件 5 MB、抽取文字总计 100,000 个字符。附件只在当前打开的会话中有效。

> 整页抓取会尽量过滤导航栏、广告和其他页面噪声。如果页面是复杂的单页应用、内容由图片组成，或提取结果为空，请改用文本选取或截图选取。
>
> PDF 当前提取可复制的文本层；扫描版 PDF 如果没有文本层，需要先进行 OCR。

### 五、选取网页中的文字解读

1. 在侧边栏的“选取模式”中选择“文本选取”。
2. 在网页中用鼠标拖选需要解释的文字。必须先在网页中完成选取，再点击侧边栏按钮。
3. 在“捕获范围”中选择“捕获选区”。
4. 点击“捕获文字”，插件会读取当前文字选区并发送给 AI。
5. 如果提示没有选中文本，请返回网页重新拖选，并确认选区仍然存在。

### 六、框选区域截图解读

1. 确认设置中的模型具备 Vision 能力。
2. 在侧边栏的“选取模式”中选择“截图选取”。
3. 将网页滚动到要识别的图表、图片、题目或其他区域。截图只针对当前可见区域。
4. 点击“捕获截图”。
5. 回到网页后，按住鼠标左键拖出矩形选区并松开。选区应足够大，宽度或高度小于约 5 像素会被视为取消。
6. 等待截图裁剪和 AI 解读完成。若要取消框选，按 `Esc` 键。

> 截图原图只保留在当前打开的会话内用于即时追问，不写入历史记录；历史中保存解读结果及后续文字问答，以避免 Base64 图片占用本地存储空间。

### 七、查看历史和切换界面

- 已完成的解读会保存在当前浏览器的本地历史记录中，可在侧边栏的“历史”区域点击查看。
- 历史记录支持单条导出或“全部导出”为 Markdown 文件；清除历史后无法从插件中恢复。
- 侧边栏和设置页右上角的“中/EN”按钮只切换插件界面语言，不会改变 AI 回答语言；AI 回答语言由“输出语言”设置控制。
- 🌙/☀️按钮用于切换深色和浅色主题。

### 八、常见问题

- **点击抓取后没有反应或提示权限不足**：在弹出的权限提示中点击“允许”，然后重试。不要在 `chrome://`、`edge://` 等浏览器内部页面上使用内容抓取功能。
- **提示网关请求失败**：确认 Base URL 没有重复的 `/chat/completions`，检查公司网络/VPN、API Key 和模型名称，并重新点击“测试连接”。
- **截图能发送但识别不出内容**：当前模型可能不支持 Vision，请换用支持图像输入的模型。
- **解读结果为空**：尝试刷新网页后重新抓取，或改用“文本选取”“截图选取”。
- **更新了新的压缩包**：先在扩展管理页移除旧版本，再对新压缩包解压并重新执行“加载已解压的扩展程序”；已打开的侧边栏建议关闭后重新打开。

## 架构与权限

- Manifest V3，`permissions`: `activeTab` `scripting` `storage` `sidePanel`；`optional_host_permissions`: `<all_urls>`（首次使用抓取/框选功能时按需申请，用户需在弹出的权限提示中点击允许；`chrome.tabs.captureVisibleTab()` 截图 API 要求必须是这个字面量通配符或 activeTab 授权，单独的 `http://*/*` + `https://*/*` 不满足其内部检查）。
- 不注册常驻 content script；`content.js` 由侧边栏在用户点击按钮时通过 `chrome.scripting.executeScript` 按需注入当前标签页。
- 结果展示在 Side Panel（Chrome 114+ / Edge 116+ 均支持）。
- LLM 调用走 OpenAI 兼容的 `/chat/completions` 接口（`stream: true`），支持文本与 `image_url` 多模态消息。
- API Key / 网关地址 / 模型名 / 输出语言，以及答题助手是否显示，均在设置页配置，只存本地浏览器，不写入代码仓库。

## 目录结构

```
src/
  background/   service worker（仅负责设置侧边栏行为）
  content/      按需注入的内容脚本：整页提取 / 文本选区 / 框选截图 UI
  sidepanel/    侧边栏主界面（触发抓取、展示流式结果、历史记录、语言/主题切换）
  options/      设置页（网关地址、API Key、模型、输出语言、答题助手开关、一键测试、语言/主题切换）
  lib/          共享类型、storage 封装、LLM 客户端（含测试连接）、prompt 构建、截图裁剪、i18n、历史导出
```

## 本地开发

```powershell
npm install
npm run build      # 产出 dist/，可直接作为"已解压的扩展程序"加载
npm run watch       # 增量构建（仍需手动在浏览器里点"重新加载"刷新扩展）
npm run typecheck   # 仅类型检查
```

## 在浏览器中加载

1. `npm run build` 生成 `dist/` 目录。
2. Chrome/Edge 打开 `chrome://extensions` 或 `edge://extensions`，开启"开发者模式"。
3. 点击"加载已解压的扩展程序"，选择本项目的 `dist` 文件夹。
4. 点击工具栏插件图标打开侧边栏；先进入"设置"（齿轮图标）填写：
   - 网关地址（Base URL，例如 `https://llm-gateway.internal.company.com/v1`）
   - API Key
   - 模型名称（需支持 vision 的模型名，用于区域截图解读）
   - 输出语言（AI 回答使用的语言，与界面语言无关）
   - "在主界面显示答题助手"（默认关闭；开启后侧边栏显示 Quiz answers 模式）
   - 填写完成后可点击"一键测试"验证网关连通性（首次会弹出一次权限确认，请点击允许）

## 已知限制 / 后续可扩展方向

- 历史记录目前无搜索/分页，条目上限 200 条，超出后自动丢弃最旧记录。
- 若网关返回的不是标准 SSE（`text/event-stream`），客户端会自动降级为一次性 JSON 解析。
- UI 语言目前仅支持中文/英文两种，深浅色主题为二选一（无跟随系统选项）。
